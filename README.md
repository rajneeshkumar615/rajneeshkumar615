<summary><h2>🚀 CodePulse AI — AI Developer Intelligence Platform</h2></summary>

<img src="https://readme-typing-svg.demolab.com?font=JetBrains+Mono&weight=800&size=32&duration=2600&pause=1400&color=10B981&center=true&vCenter=true&width=700&lines=%F0%9F%9A%80+CODEPULSE+AI" />

**Why I built it:** Judging a codebase's health and architecture manually is slow and inconsistent. CodePulse AI ingests any GitHub repo and produces a full engineering intelligence report — automatically, and in a way that's useful for both developers and recruiters.

**What it does:** repository analysis · engineering health score · AI repo chat (RAG) · roadmap generation · architecture visualization · PDF export.

| Layer | Design Decision |
|---|---|
| Analysis Pipeline | Deterministic engineering report — the AI explains computed metrics, it never invents them |
| Repository Chat | RAG-style context injection over the parsed repo |
| Data Layer | PostgreSQL + Prisma for structured, type-safe persistence |

**Architecture**
```
Browser → Next.js → Express API → LLM (OpenRouter/OpenAI) → Prisma → PostgreSQL
```

**Sample API**
```
POST /api/repositories/analyze
{
  "repoUrl": "https://github.com/user/repo"
}
```

**Structure**
```
src/
 ├─ api/
 ├─ ai/
 ├─ services/
 ├─ routes/
 ├─ middleware/
 └─ prisma/
```
